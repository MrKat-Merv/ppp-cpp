# PPP C++ 📘

Working through **[Programming: Principles and Practice Using C++, 3rd Edition](https://www.stroustrup.com/PPP3.html)**
by Bjarne Stroustrup — learning modern C++ (C++20/23) properly, one chapter at a time,
then building some projects with it.

## Layout

```
chapters/chNN/
├── drills/      # the end-of-chapter drills
├── exercises/   # the end-of-chapter exercises
└── notes/       # my chapter notes (markdown)
projects/        # bigger things built after/alongside the book
JOURNAL.md       # short dated log of what I learned
ppp              # helper script (see below)
```

## Building

Code uses `import std;` (C++23 standard library module) with Clang + libc++.

```sh
./ppp std                                 # once: build the std module into build/
./ppp run chapters/ch02/exercises/ex01.cpp
```

Compiled with `-std=c++23 -Wall -Wextra -Wpedantic -Wconversion -Wshadow`.

## Workflow

```sh
./ppp new 3 ex            # chapters/ch03/exercises/ex01.cpp from a template
./ppp run chapters/ch03/exercises/ex01.cpp
./ppp journal "narrowing: {} init catches it, = doesn't"
./ppp done 3              # mark chapter 3 finished
./ppp save                # refresh README, commit, push
```
